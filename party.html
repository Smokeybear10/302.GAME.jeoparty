How to play

Choose a clue and answer aloud. The host reveals the answer, then awards or deducts its value for one player. Either result closes the clue; choose Skip if nobody answers. Close returns an unanswered clue to the board.

This is a shared-screen game: everyone can see the answer when it is revealed. For private answers and individual buzzers, use Multiplayer.
